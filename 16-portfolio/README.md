# Week 16 · Portfolio + interview prep

> **Goal:** turn 15 weeks of work into a portfolio, a resume and interview stories.
> **Time:** about 10 hrs · **Notes:** [`notes.md`](notes.md)
> ⬅️ [Week 15](../15-production/)

---

## Session 1 · Polish (1 hr)

- [ ] **1.1** List every project in `projects/` and check that each README has: what it does, a diagram, how to run it, the **results table with numbers**, and design decisions and trade-offs.

## Session 2 · Polish (3 hrs)

- [ ] **2.1** Fix whatever's missing from 1.1, starting with `docs-copilot` and `docs-copilot-spring`.
- [ ] **2.2** Update the **main README** "Results" section to link the best numbers from each project.
- [ ] **2.3** Pin the repo on your GitHub profile ([Mrdoodler](https://github.com/Mrdoodler)).

## Session 3 · Demo + resume (1 hr)

- [ ] **3.1** Record a **3-5 min demo video**: problem → architecture → live demo → eval numbers → what you'd do next.
- [ ] **3.2** Write **resume bullets with numbers**, for example:
  - *Built a RAG service (Spring Boot, Spring AI, pgvector) improving recall@5 from X to Y with hybrid search + reranking; a CI eval gate blocks regressions*
  - *Built an MCP tool server and an agent; raised task success from X% to Y% through trace-driven error analysis*

## Session 4 · Interview prep (3 hrs)

- [ ] **4.1** **System design:** practise out loud "design a RAG system for 1M docs" and "design a support agent". Cover chunking, indexes, caching, evals, cost and latency. Use the [System Design Primer](https://github.com/donnemartin/system-design-primer) for general backend design.
- [ ] **4.2** **One story per project:** problem, a decision you made, the result (with a number).
- [ ] **4.3** Refresh SQL with [pgexercises](https://pgexercises.com/) and Java/Spring basics.

## Session 5 · Mock interviews (2 hrs)

- [ ] **5.1** 3 mock interviews: system design, coding, and a project deep-dive. Ask Claude to interview you, or a friend.
- [ ] **5.2** Update LinkedIn and your resume.
- [ ] **5.3** Fill in [`notes.md`](notes.md), then tick Week 16. 🎉

---

## ✅ Done when
- Every project README has numbers
- The demo video is recorded
- The resume is updated, and 3 mock interviews are done
